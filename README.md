# Student Management System (Backend) using CRUD Operations

A **Student Management System** built with **Python** using a modular approach. This project focuses on implementing complete backend functionality.

## Project Goal

The objective of this project is to build a production-style Student Management System by implementing every module step by step.

Current development focuses on:

* Modular design
* CRUD operations
* JSON file storage
* CSV import/export
* Backup & restore
* SQLite database support
* Console-based menus
